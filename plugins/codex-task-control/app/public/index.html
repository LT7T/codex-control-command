Ask Codex to analyze the raw statistics

A Codex task can run the installed local reporter, inspect its privacy-safe JSON and advise on context growth, expensive turns, retries, model choice and prompt experiments.

& "$env:LOCALAPPDATA\CodexTaskControl\Get-CodexUsageStats.ps1" -ThreadId <task-id> -Pretty

The report omits prompt text, command text, file paths, tool arguments, tool outputs and account identifiers. Subscription usage and model-token totals remain separate measurements.
